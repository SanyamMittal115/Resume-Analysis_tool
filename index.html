    How it works

    The original Streamlit edition used three Hugging Face pipelines for zero-shot role classification, neural summarization and NER skill detection. This Vercel edition keeps the same outputs but runs a deterministic browser analysis so your resume never leaves the device and the public deployment does not need multi-gigabyte model downloads.

    The professional summary is generated from resume structure rather than copying the first sentences: it identifies experience, education, projects, quantified impact and detected capabilities, then writes a short synthesized profile.
